# Watch Store - Static Website Hosting on AWS

This project demonstrates how to host a highly available and fast-loading static website using AWS services.

## 🔗 Links
- **Live Demo:** https://dojfh4ex4l48t.cloudfront.net
- **Source Code:** https://github.com/D8385/watch-store-aws

## 🛠️ Tech Stack
- **Storage:** Amazon S3 (Simple Storage Service)
- **Content Delivery:** AWS CloudFront (CDN)
- **Version Control:** GitHub

## 🏗️ Architecture
The website is stored in an **S3 Bucket** and distributed globally via **CloudFront** edge locations to ensure low latency and high speed.

## 🚀 Key Learnings
- Configuring S3 for static website hosting.
- Creating CloudFront distributions.
- Managing S3 Bucket Policies for security.
